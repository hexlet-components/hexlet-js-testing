# hexlet-js-testing

## Зачем это нужно

Готовое решение самостоятельной работы курса по тестированию на JS: тесты для
функции `reverse` с вынесенными фикстурами.

Смотреть стоит после того, как задание сделано самостоятельно, чтобы сверить
подход к фикстурам: входные данные и ожидаемый результат лежат отдельными
файлами, а не строками внутри теста.

## Запуск

```bash
make install
make test
```
